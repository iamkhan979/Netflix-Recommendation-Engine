# Netflix Capstone Project

## Overview
This project analyzes Netflix movie data to uncover trends in ratings, release years, and popular titles. It is built as a Jupyter Notebook using Python and data analysis libraries.

## Dataset
The dataset contains information about movies, including:
- **Movie_ID**: Unique identifier for each movie
- **Year**: Release year
- **Name**: Movie title
- **Rating**: Average user rating

## Objectives
- Clean and prepare the data for analysis
- Explore rating distributions and trends over the years
- Identify the top-rated movies
- Visualize key insights

## Tools & Libraries
- Python
- Pandas
- NumPy
- Matplotlib / Seaborn
- Jupyter Notebook (VS Code)

## How to Run
1. Clone this repository:
```bash
   git clone https://github.com/YOUR-USERNAME/YOUR-REPO.git
```
2. Install the required libraries:
```bash
   pip install pandas numpy matplotlib seaborn jupyter
```
3. Open `Netflix Capstone Project.ipynb` in Jupyter Notebook or VS Code and run all cells.
